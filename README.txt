دعوة ياسمين — نسخة GitHub Pages

طريقة النشر:
1. افتحي مستودع GitHub جديدًا أو المستودع المطلوب.
2. ارفعي جميع الملفات الموجودة داخل هذا المجلد إلى الصفحة الرئيسية للمستودع دون تغيير أسمائها.
3. افتحي Settings ثم Pages.
4. اختاري Deploy from a branch ثم main و /root واضغطي Save.

مهم:
- الموقع والصور والفيديو والتايمر والموقع وواتساب وألبوم الصور والكشط تعمل على GitHub Pages.
- نتيجة الكشط تبقى محفوظة على جهاز الضيفة نفسه.
- المشاهدات والإعجابات والتقييمات والاقتراحات مرتبطة مركزيًا بقاعدة Supabase.
- يظهر للزائرة عدد الإعجابات فقط، بينما تُحفظ المشاهدات والتقييمات والاقتراحات للمراجعة.
- تأكيد الحضور يبقى عبر واتساب صاحبة المناسبة.
